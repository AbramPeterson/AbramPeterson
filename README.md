### 🚀 About Me

* **🛡️ Security Operations:** Experienced in real-time network monitoring, threat hunting, SIEM analysis (**Splunk, ELK, Wazuh**), vulnerability scanning (**Nessus**), and **NIST SP 800-53** compliance.
* **💻 Full-Stack Development:** Building applications and tools using modern JavaScript frameworks, responsive frontend design, and server-side runtimes.
* **🖥️ Infrastructure & Networking:** Designing high-availability networks, managing **Proxmox** clusters, **pfSense** firewalls, **Docker** containers, and telemetry with **Zabbix**.
* **🎓 Education & Credentials:** M.S. & B.S. in Cybersecurity | **CompTIA CASP+**, **PenTest+**, **CySA+**, **Security+**, and **ISC2 CC**.
